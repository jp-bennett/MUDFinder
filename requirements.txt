# MUDFinder runtime dependencies.
#
# The one hard constraint is that the server and the browser client must speak
# the same Engine.IO protocol. static/js/socket.io.js is the Socket.IO 4.x
# client, which speaks protocol 4, so the server side needs python-engineio 4.x
# by way of Flask-SocketIO 5.x. Changing one without the other breaks every
# websocket handshake while the pages still render, so the failure looks like
# "the site loads but nothing works" -- tests/browser/ guards this pairing.
#
# simple-websocket provides websocket support for the threading async mode.

Flask>=3.0
Flask-SocketIO>=5.3
python-socketio>=5.0
python-engineio>=4.0
simple-websocket>=1.0
